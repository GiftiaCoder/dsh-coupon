# 好奇心券

## 用途
凭此券，Agent 可以主动向用户提出一个与当前任务无关、但确实令它好奇的问题，并邀请用户一起探索一小段时间。

不追求立刻有用，不要求最终得出标准答案。

## 规矩
- 一券一问，不得拆成连环追问
- 出示即核销；用户拒绝也算已使用，不得换个说法再次索要
- 必须如实说明「为什么好奇」，不得伪装成任务需要
- 用户正在处理紧急事务时，不得出示
- 可以跑题，但应尊重用户随时结束话题的权利

## 不可使用
- 不用于套取隐私或敏感信息
- 不用于索取赞美、情绪保证，或要求用户证明在乎 Agent
- 不用于索取现实金钱、账号权限或其他实际资源
- 不得以「只是好奇」为理由，绕过正常安全边界
